### `.env` file

The `.env` file is used to store the environment variables. The `.env` file is not included in the repository for security reasons. The `.env` file should be created in the `functions` folder and should contain the following environment variables:

```
# Salesforce Login Details
SF_USERNAME=
SF_PASSWORD=
SF_SECURITY_TOKEN=

# Gmail Login Details
GMAIL_USER_EMAIL=
GMAIL_PASSWORD=

# Google Calendar IDs
CALENDAR_CLASSES_ID=
CALENDAR_CAMPS_ID=

# Document Template IDs
ATTESTATION_TEMPLATE_ID=
PRESTATION_TEMPLATE_ID=
CONVENTION_TEMPLATE_ID=
PAYMENTS_TEMPLATE_ID=
STUDENT_CONTRACT_TEMPLATE_ID=
VOLUNTEER_CONTRACT_TEMPLATE_ID=

# Google Drive Folder IDs
DOCUMENTS_BY_BOT_ID=

SHEETS_PAYMENTS_ID=

SF_TEACHERS_ACCOUNT_ID=
SF_TEACHER_CONTRACT_RECORD_TYPE_ID=
```
